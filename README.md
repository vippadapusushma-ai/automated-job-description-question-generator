### Description

**Automated Job Description and Interview Questions Generator** is an AI-powered tool that simplifies the recruitment process by automatically creating professional job descriptions and relevant interview questions. The user provides basic details such as the **job role, required skills, experience, responsibilities, and qualifications**. The system processes this information using AI and generates a clear job description along with **technical, behavioral, and role-specific interview questions**.

This tool helps recruiters and HR teams **save time, maintain consistency, reduce manual effort, and conduct structured interviews**. It can be useful for different industries and job roles by adapting the generated content according to the specific requirements of the organization.
